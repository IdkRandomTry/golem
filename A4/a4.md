# Assignment Description

## Part 1 (7 marks): Intermediate Code Generation

Generate intermediate code from the parsed input program.

### Your tasks

**1. Design an intermediate representation (IR):**
    Three Address Code (TAC) [Quadruples]. This means that IR should be generated
    using Syntax Directed Translation (SDT) using lex and yacc.

```
Given Expression ( - a=b*-c+b*-c ), the corresponding quadruple representation
should be like the following:
```
```
op arg1 arg2 result
t1= minus c minus c t
t2=b*t1 * b t1 t
t3=minus c minus c t
t4=b*t3 * b t3 t
t5=t2+t4 + t2 t4 t
a=t5 = t5 a
```
**2. Handle simple constructs:**


```
a. Arithmetic expressions
b. Assignment statements
c. Temporary variable generation
```
**3. Explicitly show** :
    a. Input source program
    b. Generated intermediate code

## Part 2 (7 marks): Extended Intermediate Code Support

Extend your IR to support more complex constructs.

### Your tasks

**1. Handle decision making and iterative constructs:**
    a. Conditional statements (if, if-else)
    b. Loops (while, for)
**2. Generate appropriate labels and jumps (gotos) as and when required.**

## Part 3 (3 marks): Code Output Format

**Display the generated code in a clear and structured tabular format** as discussed in the
lecture slides.
Requirements:

1. Intermediate code must be printed **row-by-row from top to bottom**.
2. Use **readable temporary variable** naming (t1, t2, etc.).
3. Clearly separate source code and IR.

**Provide diagnostics during code generation**.
Requirements:

- Detect invalid expressions or unsupported constructs
- Display meaningful error messages
- Ensure program does not crash on incorrect input
